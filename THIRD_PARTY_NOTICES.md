## Transitive dependencies

The following inventory was generated by `:app:verifyRuntimeLicenses` from the resolved release runtime artifacts and each artifact's own POM. The task runs before builds and rejects missing or non-allowlisted license declarations. This checks declared licenses, not a legal audit of upstream source trees.

AndroidX WebKit is direct. Kotlin stdlib is automatically supplied by the existing Kotlin plugin. All other entries are transitive API/support requirements; removing them independently would break upstream dependencies. There is no additional DSP dependency.

## Explicitly excluded libraries

The project does not include Rubber Band Library, SoundTouch, TarsosDSP, or any GPL/LGPL/AGPL/MPL/EPL/CDDL dependency.

## Build reproducibility update

Gradle wrapper 8.13 (Apache-2.0, https://github.com/gradle/gradle/tree/v8.13.0) is build tooling, not packaged app code. Generated with the official Gradle distribution. The unused Foojay toolchain resolver was removed; JDK 17 is provided by the build environment. No new runtime dependency was added. Test JavaScript and the WAV generator are original project code.

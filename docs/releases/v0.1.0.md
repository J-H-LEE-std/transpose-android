First release of PocketTranspose: an Android app that opens YouTube (or any HTML5 media page) in an app-controlled WebView and lets you change pitch, speed and volume of what plays.

## Features
- **Transpose** −12…+12 semitones without changing tempo. The pitch shifter is built only from native Web Audio nodes, so it runs on the audio thread and works under YouTube's CSP.
- **Speed** ×0.25–×3.00, with an optional "Preserve pitch" setting
- **Gain** 0–2.00
- **Swipe-up control sheet** with −/+ steppers and sliders. Long-press a value to reset it.
- **Per-video settings:** transpose, speed and gain are remembered per YouTube video in a local SQLite database. Videos without saved values start at 0 · ×1.00 · 1.00.
- **Background playback** through a media foreground service with Pause/Stop in the notification. The site decides whether to keep playing when hidden, exactly as in a mobile browser: on YouTube this works for **Premium** accounts only.
- Fullscreen video, edge-to-edge layout that respects the system bars, and a themed launcher icon

## Privacy and licensing
- No `addJavascriptInterface` bridge is exposed to web pages.
- Logs never contain URLs. App data, including cookies, sign-ins and per-video settings, is excluded from cloud backup and device transfer.
- No third-party DSP, npm or native libraries. Runtime dependencies are AndroidX WebKit and Kotlin stdlib (all Apache-2.0); see `third-party-licenses.md` attached to this release.

## Install
Download `PocketTranspose-v0.1.0.apk`, check it against the `.sha256` file if you like, and open it on the phone (allow installs from this source when asked).

If a build from earlier testing (debug-signed, package `com.pockettranspose`) is installed, uninstall it first: its signature differs, so Android will refuse to update it. That also removes its per-video settings. From now on, debug builds use the separate package `com.pockettranspose.debug`.

## Known limitations
- Navigating back to YouTube search inside the page stops playback, as on YouTube mobile web.
- The pitch shifter is a simple time-domain design: fine for listening and practice, with some chorus-like artefacts on large shifts and about 25 ms of added latency.
- Tested on one device so far.

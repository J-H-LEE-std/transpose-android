# PocketTranspose

[English](README.md) · **한국어**

안드로이드 폰에서 YouTube 영상의 **키(음정)**, **속도**, **볼륨**을 바꿔 듣는 앱입니다. 악기 연습이나 편한 키로 따라 부르기, 그냥 듣기에 쓸 수 있습니다.

PocketTranspose는 앱 안에서 YouTube 모바일 사이트(또는 소리나 영상이 있는 다른 웹페이지)를 열고, 재생되는 소리를 실시간으로 바꿔 줍니다.

## 기능

- **키 변경:** −12~+12 반음. 템포는 그대로 둡니다
- **속도:** ×0.25~×3.00. 원래 음정을 유지할지 선택할 수 있습니다
- **볼륨:** 0~×2.00
- **영상별 설정 기억:** 같은 영상을 다시 열면 키·속도·볼륨이 그대로 돌아옵니다
- **백그라운드 재생:** 앱을 내리거나 화면을 꺼도 계속 재생됩니다. YouTube는 Premium 회원만 해당합니다(아래 참고)
- 위로 쓸어 올리는 제어판과 −/+ 버튼으로 한 손으로도 조작하기 쉽습니다

## 필요 조건

- Android 8.0 이상
- 인터넷 연결
- YouTube 백그라운드 재생을 원하면 YouTube Premium 계정

## 설치

1. 폰에서 [최신 릴리스](https://github.com/J-H-LEE-std/transpose-android/releases/latest) 페이지를 엽니다.
2. `PocketTranspose-vX.Y.Z.apk`를 내려받습니다.
3. 받은 파일을 엽니다. "출처를 알 수 없는 앱" 설치 허용을 물으면, 사용 중인 브라우저나 파일 앱에 허용해 주세요.

**업데이트:** 새 버전 APK를 같은 방법으로 설치하면 됩니다. 기존 앱 위에 그대로 업데이트되고, 저장된 설정도 유지됩니다.

APK 옆의 `.sha256` 파일로 다운로드한 파일이 손상되지 않았는지 확인할 수 있습니다. 확인하지 않아도 설치에는 문제가 없습니다.

## 사용법

1. **PocketTranspose**를 엽니다. YouTube 모바일 사이트가 열리고, 원하면 거기서 로그인할 수 있습니다.
2. 영상을 재생합니다.
3. 화면 아래의 **"Transpose" 막대를 위로 쓸어 올리거나** 탭하면 제어판이 열립니다.
4. **−/+ 버튼**이나 슬라이더로 조절합니다.
   - **Pitch:** 키(반음 단위)
   - **Speed:** 재생 속도
   - **Gain:** 볼륨
5. 제어판은 아래로 쓸어 내리거나, 막대를 탭하거나, 뒤로가기를 누르면 닫힙니다. 막대에는 현재 설정이 `+2 st · 1.00x · gain 1.00`처럼 표시됩니다.

설정은 **그 영상 기준으로 자동 저장**됩니다. 한 번도 조절하지 않은 영상은 키 0, 속도 ×1.00, 볼륨 1.00으로 시작합니다.

값 하나만 되돌리려면 그 값을 길게 누르세요. **Reset**을 누르면 세 가지가 모두 기본값으로 돌아가고, 이 영상에 저장된 설정도 지워집니다.

위쪽 주소창에 다른 주소를 입력하면, 소리나 영상이 있는 다른 사이트에서도 똑같이 조절할 수 있습니다.

### 제어판의 다른 항목

| 항목 | 기능 |
| --- | --- |
| Preserve pitch on speed change | 켬(기본): 속도를 바꿔도 키가 유지됩니다. 끔: 테이프처럼 빠르게 하면 음도 높아집니다. |
| Identify as Chrome (Premium background play) | YouTube가 이 앱을 Chrome 브라우저처럼 인식하게 합니다. Premium인데 백그라운드 재생이 안 될 때만 써 보세요. 켜면 페이지가 새로고침됩니다. |
| YouTube | YouTube 첫 화면으로 돌아갑니다. |
| Test page | 짧은 음을 재생하는 내장 페이지입니다. 조절 기능이 동작하는지 확인할 때 씁니다. |
| Reinject | 조절해도 소리가 바뀌지 않을 때 다시 연결합니다. |
| Status | 기술 정보를 보여 줍니다. 문제를 알릴 때 도움이 됩니다. |
| Probe only | 개발자용 진단 기능입니다. 꺼 두세요. |

## 백그라운드 재생

처음 재생할 때 알림 권한을 한 번 묻습니다. 재생 중에는 **"PocketTranspose is playing"** 알림이 뜨고, 거기서 일시정지하거나 정지할 수 있습니다.

- **YouTube:** 백그라운드에서 계속 재생할지는 모바일 브라우저와 똑같이 YouTube가 정합니다. **YouTube Premium**이면 계속 재생되고, Premium이 아니면 앱을 벗어날 때 멈춥니다. PocketTranspose는 이 제한을 우회하지 않습니다.
- **다른 사이트:** 대부분의 소리와 영상은 그대로 계속 재생됩니다.
- Premium인데도 멈춘다면 제어판에서 **Identify as Chrome**을 켜 보세요.
- YouTube 안에서 검색 결과로 돌아가면 재생이 멈춥니다. YouTube 모바일 사이트도 똑같이 동작합니다.

## 문제 해결

**슬라이더를 움직여도 소리가 안 바뀌어요**
영상이 실제로 재생 중인지 확인한 뒤 **Reinject**를 눌러 보세요. **Test page**에서 Pitch를 움직였을 때 음이 바뀌면 정상입니다.

**키를 크게 바꾸면 소리가 조금 거칠어요**
키 변경 기능의 알려진 한계로, ±12 근처에서 가장 두드러집니다. 작게 바꿀 때는 깨끗하게 들립니다.

**키를 바꾸면 소리가 화면보다 아주 살짝 늦어요**
키 변경에 약 20~30ms의 지연이 생깁니다. 음악을 들을 때는 거의 느껴지지 않는 수준입니다.

**앱을 벗어나면 재생이 멈춰요**
YouTube는 Premium이 아니면 원래 멈춥니다. Premium이라면 위의 **Identify as Chrome**을 켜 보고, PocketTranspose의 알림이 허용돼 있는지도 확인해 주세요.

## 개인정보

- PocketTranspose에는 계정, 광고, 분석 도구, 자체 서버가 없습니다. 사용자가 연 사이트하고만 통신합니다.
- YouTube 로그인은 YouTube 페이지에서 이루어지고, 로그인 정보는 앱 안에만 남습니다.
- 영상별 설정은 폰에만 저장되고, 클라우드 백업과 기기 이전에서도 빠집니다.

## 관련 없음 안내

PocketTranspose는 개인이 만든 취미 프로젝트입니다. YouTube, Google, "Transpose" 브라우저 확장 프로그램과는 관계가 없고, 그들의 승인을 받지 않았습니다. 광고를 차단하거나 YouTube의 제한을 우회하지 않습니다.
